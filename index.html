3. Local Wi-Fi / Device Print

Uses the browser’s native print dialog. Works with AirPrint, Mopria, or any installed Epson driver on the same network.

Tip: Make sure your Epson printer is connected to the same Wi-Fi network and appears in your device’s printer list (or use Epson Smart Panel app for discovery).

3. Email Print (Epson Connect)

Send the file to your printer’s unique Epson Connect email address. Works from anywhere (Wi-Fi or mobile data).

Find this address after registering the printer at epsonconnect.com or in the Epson Smart Panel app.

How it works: The app opens your email client (or creates a mailto link) with the file attached. The Epson cloud receives the message and sends the job to the printer over the internet.

3. Epson Connect API (Developer)

Full programmatic printing using the official Epson Connect API v2. Requires a developer license from developer.epsonconnect.com.

Note: This demo runs in the browser. Real API calls need a backend (CORS + secrets). See the api-example.js and README for a Node.js / Python skeleton that uses the official flow:
  1. Authenticate (OAuth2) → obtain device token
  2. Create print job
  3. Upload file
  4. Execute print
